# 🧮 Calculator — Console-Based C++ Math Utility

A C++ project implementing a **console-based calculator** capable of performing basic arithmetic, square root, and logarithm operations. The program handles user input, validates it, and checks for arithmetic errors like overflow, underflow, division by zero, and invalid arguments.

This project showcases:

- Basic arithmetic operations: add, subtract, multiply, divide  
- Advanced operations: square root and natural logarithm  
- Input validation and exception handling  
- Menu-driven interactive console interface
